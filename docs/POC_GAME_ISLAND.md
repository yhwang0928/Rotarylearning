## 試玩流程

1. 開啟 `/poc/`，選擇六種人物外觀之一，輸入暱稱。
2. 點選建築，或按「想去哪裡？」選擇學區。
3. 人物沿固定道路行走，鏡頭跟隨；可拖動地圖、切換全景或暫停。
4. 抵達後閱讀短課程，也可用「直接進入」略過走路。
5. 答對一題完成該區體驗課，首次獲得 10 點。
6. 五區全部通過後再獲得 20 點，總計 70 點及全島探索家稱號。
7. 開啟右上角的學習護照，查看進度、印章、更換人物及暱稱。
8. 重新整理同一網址，驗證角色、已完成學區及點數能恢復。

## 本次已實作

- 自行建立的 Three.js 校園：五個場域、中央地球噴泉、樹木、公園、道路與入口。
- 六種共用動作結構的 3D 人物外觀，以及實際人物預覽和縮圖。
- 人物肢體走路動畫、平滑轉向、地面陰影、道路節點尋路與重新選擇目的地。
- 四位環境人物，包含自主散步、閱讀與澆花姿態。
- 桌機旋轉、右鍵平移、滾輪縮放；觸控拖曳平移、雙指縮放／旋轉。
- 五區各一份 POC 短課程與一道測驗，附官方來源連結。
- 答錯重試、重讀、完成回饋、首次發點、全島獎勵、進度印章。
- `localStorage` 存檔、重新整理恢復、換外觀保留進度及 JSON 測試紀錄匯出。
- 儲存不可用時顯示提示；WebGL 不可用時保留靜態圖與可操作的學區選單。
- 彈窗開啟時暫停場景動作，支援系統減少動態偏好及可用鍵盤完成的目的地／課程選單。

## 長輩易讀版（2026-11-05）

- 主要內文、表單與主要按鈕預設 18px，次要操作 16px、補充說明至少 14px；標題 26–32px，點數 38px。
- 提供「特大字」切換：主要內文與按鈕 20px、次要文字 18px、補充說明 16px，並在同一瀏覽器記住設定。
- 各彈窗內也能切換字級；課程、學區與護照的關閉操作改為具文字的固定工具列。
- 統一使用中文黑體，加深輔助文字顏色；行距、選項間距及按鈕高度一併放大。
- 手機選角改兩欄、護照印章改兩欄；操作按鈕清楚分排，長文可捲動，保留可見捲軸。
- 首次選角明確標出「選擇人物」「輸入暱稱」；題目與按鈕改用較短的中文。
- 選角與答案選取增加勾選符號及文字，不只依賴顏色判斷。
- 同一網址的既有角色、進度與點數保留；字級偏好使用獨立儲存鍵，不改動玩家資料結構。

易讀版驗證：桌機 1280×720 的一般／特大字、390×844 的一般／特大字，以及 320px 特大字；檢查選角、課程、題目、護照與長達 12 字的暱稱。已量測 18px／20px 主要字級、確認彈窗無水平溢出，並操作重考與重新整理，原有 70 點紀錄保留。六項核心自動測試通過，瀏覽器未觀察到 console error。

未進行長輩使用者訪測、手機實機與瀏覽器 200% 文字縮放驗證，不將窄視窗檢查視為上述測試已完成。

## POC 限制

- 尚未建立 LINE、雲端帳號、後端判分、正式資料庫或跨裝置同步。
- 存檔與網址來源綁定：localhost、預覽網址與正式網址各自有獨立紀錄。測試請固定使用同一個網址。
- 清除瀏覽資料、使用不同瀏覽器或更換裝置，都不能自動恢復本機紀錄。
- 匯出功能供保留測試紀錄，本版未提供匯入介面。
- 點數在前端計算，可以被本機修改；本版用於驗證體驗，不適合正式兌獎或排行榜。
- 六種人物為程式製作的模型原型，還不是最終客製角色美術。
- 每區只有一堂短課程／一道題；完成不代表正式扶輪課程學分或社員資格。
- 同一裝置的同一瀏覽器共用一份玩家存檔，未提供多人帳號切換。

## 程式結構

| 檔案 | 職責 |
| --- | --- |
| `dist/poc/index.html` | 場景容器、選角、目的地、課程與護照彈窗 |
| `dist/poc/styles.css` | 桌機與手機介面、字體、顏色與狀態 |
| `dist/poc/app.js` | 首次進入、選角、課程／測驗 UI、存檔整合 |
| `dist/poc/scene.js` | Three.js 場景、角色、動作、鏡頭與選取 |
| `dist/poc/routes.js` | 道路節點、邊與尋路 |
| `dist/poc/data.js` | 角色外觀、五區教材、題目與獎勵設定 |
| `dist/poc/state.js` | 名稱驗證、玩家資料、完成規則、分數推導與儲存 |
| `tests/poc.test.mjs` | 點數、存檔、名稱與道路連通測試 |
| `scripts/vendor-three.mjs` | 複製鎖定版本的 Three.js 與授權到可部署目錄 |

Third-party dependency：Three.js 0.187.0（MIT）；授權保留於 `dist/poc/vendor/THREE-LICENSE.txt`。場景核心依賴隨網站部署，不需外部 JavaScript CDN。Google Fonts 載入失敗時使用系統字體。

## 本機執行

```bash
npm ci
npm test
npm run preview
```

開啟 <http://localhost:4173/poc/>。`dist` 已包含 vendor，單純預覽亦可直接使用 Python 靜態伺服器。
