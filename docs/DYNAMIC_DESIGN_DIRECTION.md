# 扶輪知識島動態設計方向

## 關鍵字定義

「比照 Puma 政策島的動態設計」代表採用空間探索與資訊互動方法，不代表複製其品牌視覺。

設計公式：

> Puma 式 3D 動態互動架構＋目前扶輪知識島的可愛校園美術

## 核心互動

| 功能 | 桌機 | 手機 |
| --- | --- | --- |
| 校園探索 | 拖曳旋轉、滾輪縮放 | 單指拖曳、雙指縮放 |
| 選取建築 | 金色輪廓、浮動定位點 | 金色輪廓、觸控定位點 |
| 課程資訊 | 右側浮動資訊卡 | 可上拉的底部抽屜 |
| 知識索引 | 左側搜尋與分類 | 底部導覽進入索引 |
| 知識關聯 | 建築間柔和光線 | 選取後顯示精簡關聯線 |
| 主要導覽 | 全景、知識索引、扶輪年度、學習手冊 | 全景、知識、年度、手冊 |

## 美術不變項

- 藍金屋頂、奶油色石材、明亮海水與大量花園植栽。
- 圓潤、精緻、像立體模型或溫暖遊戲世界的材質。
- 可愛友善的人物比例，不使用寫實或嚴肅公部門視覺。
- 扶輪藍與扶輪金作為功能重點色，使用正確扶輪識別。

## 技術建議

- Three.js `WebGLRenderer`、`PerspectiveCamera`、受限 `OrbitControls`。
- `Raycaster` 處理建築點選，`CSS2DRenderer` 顯示場域標籤。
- 建築與環境使用 GLB／glTF；課程內容與 3D 場景資料分離。
- 手機使用 bottom sheet，不縮小桌機側欄。
- 加入像素密度與品質分級、靜態備援、減少動態模式及鍵盤可用替代介面。

## 第一階段驗收

- 五個主要建築均可在 3D 場景中被選取。
- 桌機可旋轉與縮放，且鏡頭不會離開校園有效範圍。
- 手機可拖曳、雙指縮放，底部抽屜不遮住目前選取建築。
- 場景選取、知識索引與課程資訊三者狀態同步。
- 中低階手機仍能操作；WebGL 不可用時顯示目前靜態校園版本。
